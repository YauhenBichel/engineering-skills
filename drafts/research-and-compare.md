## Steps
1. Define criteria. Assign weights 0.0–1.0. Ensure weights sum to 1.0.
2. Collect 2–4 options. Include "Do nothing" as a baseline.
3. Gather facts. Separate vendor claims from measurements. Tag each. Record source URLs or run `curl`/`npm info`/`pip index`.
4. Score options. Multiply each metric by its weight. Sum for total score.
5. Draft comparison table. Columns: Option, Weighted Score, Pros, Cons, Cost.
6. State recommendation. Name the top option. Give one-sentence reason.
7. List unverified items. Note exact commands to validate them.

## Checklist
- [ ] Criteria weights sum to 1.0
- [ ] Options include "Do nothing"
- [ ] Facts tagged and separated by source type
- [ ] Table reflects weighted scores
- [ ] Recommendation cites top score
- [ ] Unverified items list test steps
- [ ] No marketing language remains

## Output
- Weighted criteria list
- Comparison table and ranked options
- Recommendation with reason and unverified items
